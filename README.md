# TodoManager

A console task manager written in C# (.NET 8) to practice core C# concepts.

## Features
- Add, view, delete and complete tasks
- Priority (Low / Medium / High) and due date with time
- Pending and overdue views, plus statistics
- Saves to a JSON file
- Unit tests with xUnit

## Concepts practiced
Classes, collections, LINQ, enums, interfaces, exception handling,
file I/O (System.Text.Json), records, unit testing.
